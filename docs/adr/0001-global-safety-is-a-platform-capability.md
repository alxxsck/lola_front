# Global Safety is one platform capability, not an operator-built ML bundle

Lola publishes one immutable Global Safety Policy for every Project and every supported message,
while a Platform Operator selects only an admitted xAI model and reasoning depth. The server owns
the risk taxonomy, coverage, output contract, fail-closed behavior and consequences; classifier,
calibrator and dataset identifiers are not part of the product API. This deliberately gives up
per-locale threshold tuning until Lola has a real evaluation and calibration pipeline, rather than
asking operators to manufacture evidence that the platform cannot create or verify.
